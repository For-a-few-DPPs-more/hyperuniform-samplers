# Hyperuniform Point Clouds Database

This is the GitHub companion repository of the Hyperuniform samples database stored on [Zenodo](https://doi.org/10.5281/zenodo.23405562). The database contains hyperuniform point clouds (e.g. blue noise) on the unit hypercube [0,1)ᴰ, sampled with the [blue-sampler](https://pypi.org/project/blue-sampler/) Python package.

**2D example** (the N = 1024, D = 2, Chi43 point clouds of this database):

![2D example, N = 1024, chi43](https://zenodo.org/records/23405562/files/plot_2D_sample_chi43.png)

## Installation

```
pip install numpy h5py
```

## Quick Start

First clone this repository:

```
git clone https://github.com/For-a-few-DPPs-more/hyperuniform-samplers.git
cd hyperuniform-samplers
```

Then, from the terminal, load the full database and generate a new randomized point cloud:

```
python src/load_data.py --dim all --chi all
python src/new_data.py --dim 2 --npoints 1024 --chi 30 --seed 42
```

Or from a notebook: open `quick_start.ipynb` and follow the instructions.

## Data characteristics

- **Format:** HDF5 (Python, C++, MATLAB, Julia, R, ...).
- **Size:** ≈ 712 MB by default, ≈ 3.4 GB with the large point clouds (see note below).
- **Number of points:** native N = 2¹⁰ to 2¹⁷ (powers of 2); up to N = 2²⁴ with tiling.
- **Dimension:** native D = 2 to 16, plus D = 23 and D = 32; any 2 ≤ D ≤ 32 with projection.

[![ND_coverage](./plots/coverage_table_ND.png)](./plots/coverage_table_ND.png)

> **Note: Large storage.** In low dimensions (D ≤ 4), the Zenodo database provides additional, much larger point clouds, to be downloaded manually ([`larges.zip`](https://zenodo.org/records/23405562?preview_file=larges.zip), 2.7 GB). They go up to N = 2²⁷ ≈ 134 million points in 2D, 2²⁵ ≈ 34 million in 3D and 2²¹ ≈ 2 million in 4D.

## Sampling method

The samples were generated by **spectral optimisation** (non-uniform Fourier transform): select a spectral exclusion region, initialise with a random point cloud, then run a gradient descent on the Fourier loss. Each resulting point cloud comes in four versions:

- χ = 0.30: stealthy scattering intensity S(k) ≤ 10⁻¹⁰ in a standard Euclidean ball of wave vectors;
- χ = 0.43: S(k) ≤ 10⁻3 only, but in a ball with x1.5 bigger volume;
- χ = L1-0.43: S(k) ≤ 10⁻3 inside an L1 ball (`‖k‖₁ = Σ|kᵢ|`);
- χ = WD-0.43: S(k) ≤ 10⁻2 inside an WD exclusion region.
      An WD exclusion region (looks like a star) is definied as r(k) <= cst were r(k) is the fourier coefficient of the wrap around discrepancy.

Spectral exclusion regions for the four versions, with N = 1024, D = 2:

[![exclusion_regions](./plots/exclusion_balls.png)](./plots/exclusion_balls.png)

## Guarantees

### Stealthiness

For a wave vector k = (k₁, ..., k_D) with integer components,

```
S(k) = |Σⱼ exp(2iπ ⟨k, xⱼ⟩)|² / N
```

A near-zero S(k) means that the Monte Carlo integration error is controlled for the low-frequency test function x ↦ exp(2iπ ⟨k, x⟩).

### Randomisability

Spectral optimisation enforces periodic boundary conditions, so a sample can be randomised by a simple shift:

```
X_new = (X - s) mod 1, s drawn uniformly in [0,1]^D
```

### Extensibility

`src/load_data.py` downloads the samples with 2¹⁰ ≤ N ≤ 2¹⁷ and D = 2 to 16 plus 23, 32. Other (N, D) shapes are produced on the fly by `src/new_data.py`, at a controlled loss of quality:

- **Tiling** (more points): copies of the periodic point cloud are combined into a larger one, up to N = 2²⁴. The stealthiness degrades proportionally to the increase in points:

  ```
  sup S_t(k) = sup S(k) × N_t / N
  ```

  where N is the original number of points and N_t the number after tiling. See [TILING.md](infos/TILING.md).

  ![Tiling effect](./plots/tiling_effect.png)

- **Projection** (lower dimension): 17 ≤ D_proj ≤ 22 is projected from D = 23, and 24 ≤ D_proj ≤ 31 from D = 32. See [PROJECTION.md](infos/PROJECTION.md).

## Use cases

- **Rendering and blue noise:** anti-aliasing, path tracing, dithering, denoising textures.
- **Spatial sampling:** isotropic particle initialisation (SPH, molecular dynamics) with periodic boundary conditions.
- **Monte Carlo / QMC integration:** periodic or smooth integrands (`L1-43` by default, `WD-43` for low effective dimensionality). Random shifts give independent replicas and error bars.
- **Machine learning and design of experiments:** initial designs, uncertainty quantification.
- **Hyperuniformity research:** reference data to study structure factors and to benchmark new samplers.

> **Note - discrepancy:** This database  is not drop-in replacements for Sobol or Halton sequences: they show slightly weaker discrepancy according to `scipy.stats.qmc.discrepancy` (see [BENCHMARK.md](infos/BENCHMARK.md)). They are complementary strategies, worth exploring when the integrand has favourable low-frequency spectral properties. 

> **Note - adaptative sampling** Although this database contains only uniform samples, spectral methods proposed in [SAMPLING.md](infos/SAMPLING.md) support adaptative sampling, by passing a target distribution to the sampler. This could be of use for importance sampling or when one require well distributed points, but under a specific spatial distribution.
